# My Applications

**My Applications** — кроссплатформенное настольное приложение (Windows 10/11 и Linux) для создания
личного каталога программ, игр, сайтов, сервисов и других цифровых ресурсов.

Приложение работает **полностью локально (offline first)**: нет облачных сервисов, внешних API,
аккаунтов и обязательного подключения к интернету. Все данные хранятся в SQLite в вашем профиле.

---

## Возможности

- **Две панели**: каталог слева, подробная информация справа (размер панелей меняется перетаскиванием).
- **Записи** с названием, типом, описанием, категорией, тегами, ссылками и иконкой.
- **Поиск в реальном времени** по названию, фильтры по категории и по нескольким тегам, 6 режимов сортировки.
- **Ссылки**: любое количество на запись, изменение порядка, открытие в системном браузере.
- **Изображения**: PNG, JPG/JPEG, WEBP, ICO, GIF, BMP, TIFF. Копия файла сохраняется внутри хранилища,
  автоматически создаются миниатюры; пропорции не искажаются.
- **Скачивание иконок с сайта** — по явному нажатию кнопки (см. ниже), с таймаутом и лимитами.
- **Стартовый каталог** при первом запуске: Steam, Epic Games, Battle.net, OpenCode, Firefox,
  Telegram, Happ, Zapret и TgWsProxy — можно отредактировать или удалить.
- **Категории и теги**: создание, переименование, удаление, фильтрация по тегам.
- **Автосохранение** всех изменений, безопасные транзакции SQLite (WAL, внешние ключи, индексы).
- **Резервное копирование**: автоматические снимки базы по расписанию с ротацией, ручные ZIP-копии.
- **Восстановление** с проверкой структуры архива, версии формата и изображений до изменения данных;
  перед импортом создаётся снимок текущего состояния.
- **Экспорт / импорт ZIP** для переноса данных между устройствами (merge или полная замена).
- **Тёмная тема по умолчанию** и светлая тема, русский и английский интерфейс.
- **Журналирование** в файл с настройкой уровня; ошибки не приводят к потере данных.

## Установка

Требуется Python 3.11+ (проверено на 3.11.9, Windows 11; код не использует платформенных API,
кроме путей к каталогу данных).

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux
source .venv/bin/activate

pip install -r requirements.txt
```

Для тестов и сборки:

```bash
pip install -r requirements-dev.txt
```

## Запуск

```bash
python main.py
```

Полезные ключи:

```bash
python main.py --data-dir "D:/MyStorage"   # собственный каталог данных
python main.py --version                   # версия приложения
```

Переменная окружения `MY_APPLICATIONS_HOME` переопределяет каталог данных.

## Расположение данных

| Платформа | Путь |
|---|---|
| Windows | `%APPDATA%/MyApplications/` |
| Linux | `$XDG_DATA_HOME/MyApplications/` или `~/.local/share/MyApplications/` |

```text
MyApplications/
├── database.db            # SQLite (WAL)
├── Images/
│   ├── entries/           # копии пользовательских изображений
│   └── thumbnails/        # миниатюры 192×192
├── Backups/
│   └── auto/              # автоматические снимки базы
├── Logs/
│   └── application.log
└── config/
    └── settings.json
```

## Горячие клавиши

| Клавиши | Действие |

## Архитектура

```text
main.py                  точка входа (QApplication + главное окно)
app/
├── application.py       composition root: собирает все слои
├── paths.py             каталоги данных, безопасные пути
├── events.py            шина событий между слоями
├── models/              dataclass-модели (Entry, Link, Category, Tag)
├── database/            соединение, схема, миграции, репозиторий (единственное место с SQL)
├── data/                стартовый каталог (чистые данные, без доступа к БД)
├── services/            бизнес-логика: записи, категории, теги, поиск, бэкапы, стартовый каталог
├── images/              импорт изображений, миниатюры (Pillow), загрузка иконок с сайта
├── storage/             ZIP-архивы, восстановление, работа с файлами
├── settings/            settings.json с валидацией
├── utils/               валидаторы, логирование, вспомогательные функции, фоновые задачи
└── ui/
    ├── windows/         главное окно, окно настроек
    ├── widgets/         боковая панель, панель деталей, редактор тегов, общие элементы
    ├── dialogs/         запись, ссылка, категории и теги
    └── styles/          QSS темы и набор SVG-иконок
tests/                   pytest: валидаторы, БД, сервисы, бэкапы, UI smoke
packaging/               PyInstaller spec
```

Правила слоёв:

- UI **не выполняет SQL** и не работает с файлами напрямую — только через сервисы.
- SQL живёт исключительно в `database/repository.py`.
- Бизнес-логика — в `services/`; файловые и архивные операции — в `storage/` и `images/`.
- Долгие операции (бэкап, импорт/экспорт) выполняются в фоновом пуле потоков, UI не блокируется.

### Схема базы данных

| Таблица | Назначение |
|---|---|
| `entries` | записи: UUID, название, описание, тип, категория, изображение, даты |
| `links` | ссылки: UUID, запись, название, URL, порядок |
| `categories` | категории (уникальное имя без учёта регистра) |
| `tags` | теги (уникальное имя без учёта регистра) |
| `entry_tags` | связь записей и тегов (каскадное удаление) |
| `app_meta` | служебные метаданные |

Версия схемы хранится в `PRAGMA user_version`; `database/migrations.py` применяет миграции поверх
существующей базы без потери данных.

## Резервное копирование и перенос

**Автоматически** (раз в 6/12/24/72/168 часов, настраивается): через SQLite Backup API создаётся
снимок `.db` в `Backups/auto/`, старые копии удаляются по лимиту.

**Вручную**: ZIP-архив со структурой

```text
MyApplications_Backup.zip
├── manifest.json              формат и версия
├── database.json              записи, ссылки, категории, теги, изображения
├── metadata/backup_info.json  счётчики и версии
└── Images/                    копии иконок
```

Перед импортом архив проверяется: структура ZIP, безопасность путей, обязательные файлы,
валидность JSON, версия формата, наличие всех изображений. Данные не изменяются, пока проверка
не пройдена. Режим `merge` добавляет новые записи, `replace` полностью заменяет данные (с
предварительным снимком текущей базы).

## Тесты

```bash
python -m pytest tests -q
```

Покрыто: валидация URL и полей, CRUD записей, ссылки и их порядок, категории/теги, поиск с
экранированием `LIKE`, каскадные удаления, откат транзакций, повреждённая БД, импорт/экспорт,
некорректные и вредоносные архивы, ротация авто-копий, настройки, стартовый каталог, скачивание
иконок (сеть подменена в тестах), UI smoke-тесты (поиск, фильтры, диалоги, переключение темы).

## Сборка

```bash
pip install -r requirements-dev.txt
python build.py            # один самодостаточный файл
python build.py --clean    # с очисткой артефактов
```

Результат — **отдельный исполняемый файл**:

| Платформа | Файл |
|---|---|
| Windows | `dist/MyApplications.exe` (~150–200 МБ) |
| Linux | `dist/MyApplications` |

Внутри один файл уже содержит Python, Qt и Pillow, поэтому **рядом ничего не нужно** — его можно
скопировать на другой компьютер и запустить. При старте он распаковывается во временный каталог,
поэтому первый запуск занимает несколько секунд.

Если нужна сборка «папкой» (стартует быстрее, но требует копировать весь каталог):

```bash
# Windows PowerShell
$env:MYAPPLICATIONS_ONEFILE="0"; python build.py
# Linux
MYAPPLICATIONS_ONEFILE=0 python build.py
```

На Linux собирайте на целевой системе — PyInstaller не кросс-компилирует. Для Linux дополнительно
могут потребоваться системные библиотеки Qt (`libxcb`, `libEGL`, шрифты), как для любого
Qt-приложения.

## Скачивание иконок с сайта

Приложение остаётся offline-first: **единственный** сетевой запрос возможен только по явному
нажатию кнопки «Скачать иконку с сайта» в диалоге записи. Что происходит:

1. Адрес сайта подставляется из первой http(s)-ссылки записи, его можно изменить.
2. Скачивается страница и ищутся объявления `<link rel="icon">` / `apple-touch-icon`;
   если их нет — запрашивается `/favicon.ico`.
3. Проверяются тип файла (по сигнатуре), размер (до 5 МБ) и то, что это действительно
   изображение. Любая ошибка показывается в диалоге и ничего не сохраняет.
4. Байты остаются в памяти до сохранения записи: если передумать и закрыть диалог,
   мусорных файлов не остаётся.

Никакой телеметрии, аккаунтов и фоновых обращений к сети нет.

## Стартовый каталог

При первом запуске (пустая база) добавляются 9 записей: Steam, Epic Games, Battle.net,
OpenCode, Firefox, Telegram, Happ, Zapret и TgWsProxy. Они помечены версией в `app_meta`,
поэтому после удаления больше не возвращаются, а в непустую базу не добавляются никогда.
Иконки не входят в поставку — их можно скачать кнопкой выше.

## Ограничения

- Нет синхронизации между устройствами «онлайн» — перенос только через ZIP-архив.
- Нет предпросмотра веб-страниц: ссылки открываются в системном браузере.
- Автоматические копии — это снимки базы (без изображений); полный ZIP создаётся вручную.
- Скачивание иконок работает по одному адресу за раз и только для сайтов http/https.
